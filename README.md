# DieFliegendeKuh — тренажёр немецких неправильных глаголов

Один HTML-файл (`DieFliegendeKuhApp.html`), тренирует все **270 базовых неправильных глаголов** немецкого. Работает офлайн в любом браузере — установка, сервер и интернет не нужны.

## Быстрый старт
1. Скачайте `DieFliegendeKuhApp.html` из репозитория.
2. Откройте файл двойным кликом — он запустится в браузере по умолчанию.

Пошаговая инструкция — в [HOWTOUSE.md](HOWTOUSE.md).

## Что внутри
Оформление — зелёная ретро-тема **CRT Phosphor** (моноширинный шрифт, фосфорное свечение) в светлом и тёмном варианте. В правом верхнем углу — кнопка темы ☀️/🌙 и кнопка языка интерфейса (тап переключает **RUS → ENG → ITA**), ниже — три вкладки:

- **🎯 Тренажёр** — по выбранному диапазону глаголов вводите перевод и форму **Perfekt** (`hat abgebrochen`), в конце — разбор ошибок.
- **📖 Словарь** — таблица всех 270 глаголов: формы, перевод, поиск, фильтры, режим самопроверки (скрыть перевод/Perfekt).
- **🗂️ Карточки** — интерактивная колода для запоминания: инфинитив + формы → перевод → чистая иллюстрация с примером предложения; пролистывание жестом вправо/влево (или ←/→).

Отдельной кнопкой **💬 Small Talk** на главном экране открывается тренажёр Small Talk к экзамену **DTB B2**: карта с двумя скрытыми темами (77 тем), таймер 2 минуты на каждую, перевод тем — на выбранном языке интерфейса.

Прогресс единый для всех вкладок — 4 статуса (📘 Новое / 🟡 Повторено / 📕 Невыученное / 📗 Выучено), сохраняется в браузере автоматически, плюс экспорт/импорт в JSON.

## Иллюстрации для «Карточки»
Встроены прямо в `DieFliegendeKuhApp.html` — сейчас заполнено 83 из 270, для остальных показывается нейтральная заглушка. Исходники (`verb-images/NNN-infinitiv.webp`) хранятся локально и в репозиторий не входят; новые картинки встраиваются скриптом `python tools/embed-verb-images.py`. Формат и правила — в [tools/verb-images.md](tools/verb-images.md).
