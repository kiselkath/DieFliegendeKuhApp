# Как установить и начать пользоваться DieFliegendeKuh

Приложение — это один HTML-файл `DieFliegendeKuhApp.html`. Ему не нужен сервер, установка или интернет: он работает прямо в браузере.

## 1. Скачать файл

Выберите один из вариантов.

**Вариант А — без Git (проще всего):**
1. Откройте страницу репозитория: https://github.com/kiselkath/DieFliegendeKuhApp
2. Нажмите на файл `DieFliegendeKuhApp.html`.
3. Нажмите кнопку **Download raw file** (или значок скачивания).
4. Сохраните файл на компьютер (например, на Рабочий стол).

**Вариант Б — через Git:**
```
git clone https://github.com/kiselkath/DieFliegendeKuhApp.git
```
Файл `DieFliegendeKuhApp.html` появится в скачанной папке.

## 2. Открыть приложение

Дважды кликните по файлу `DieFliegendeKuhApp.html` — он откроется в браузере по умолчанию (Chrome, Firefox, Edge, Safari — подойдёт любой современный браузер).

Если файл не открылся сам: откройте браузер и перетащите файл в окно браузера, либо `Файл → Открыть файл...`.

## 3. Выбор языка

Вверху страницы есть переключатель **RUS/ENG/ITA** — он меняет и язык интерфейса, и язык, на котором нужно вводить перевод в тренажёре и который показывается в словаре. Выбор запоминается в браузере.

## 4. Тема оформления

Оформление одно — зелёная ретро-тема **CRT Phosphor** (в стиле старого монитора: моноширинный шрифт VT323/Handjet, фосфорное свечение в тёмном режиме, «зелёная бумага» в светлом).

Слева от переключателя языка — кнопка 🌙/☀️: тёмный/светлый вариант темы. По умолчанию — **светлый**, выбор запоминается в браузере.

## 5. Вкладка «Тренажёр»

1. Вверху страницы выберите вкладку **🎯 Тренажёр**.
2. Задайте диапазон глаголов — вручную («от … до») или пресетом по 35 (1–35, 36–70 и т.д., либо «Все 1–270»). Кнопка «Начать» станет активной только после того, как диапазон выбран корректно.
3. Выберите режим: весь диапазон / новые + невыученные + повторённые / только невыученные / только повторённые / только выученные.
4. Нажмите **Начать**.
5. Для каждого глагола (инфинитив, например `abbrechen`) введите:
   - перевод (на русский, английский или итальянский — в зависимости от выбранного языка);
   - форму **Perfekt** со вспомогательным глаголом (например, `hat abgebrochen`).
6. Перевод проверяется мягко (по корню слова), Perfekt — строго, но с учётом допустимых вариантов (`hat`/`ist`, `angewendet`/`angewandt` и т.п.) и умлаутов как `ae`/`oe`/`ue`/`ss`.
7. Если считаете свой ответ верным, а система не засчитала — используйте кнопку «засчитать/ошибка», чтобы скорректировать оценку вручную.
8. В конце теста откроется экран результатов: цветные счётчики 📗/📕/🟡/📘 показывают состояние **по всем 270 глаголам**, а не только по диапазону теста. Для 📗 Выучено и 📕 Невыучено число дано в формате «было + за эту сессию = итого» (например `142 + 5 = 147`). Ниже — **разбор ошибок**: таблица «ваш ответ vs правильный ответ».
9. Глаголы автоматически распределяются по папкам: 📗 Выучено / 📕 Невыучено / 📘 Новые (🟡 «Повторено», если ошиблись/угадали, остаётся в общем пуле до подтверждения).

## 6. Вкладка «Словарь»

1. Переключитесь на вкладку **📖 Словарь**, чтобы полистать все 270 глаголов перед тестом.
2. Для каждого глагола видно: №, инфинитив (+ подсказка для омонимов), Präsens · Präteritum, Perfekt (цвет показывает `hat`/`ist`), перевод и папку-статус.
3. Ищите глагол по номеру, инфинитиву, переводу или Perfekt через строку поиска.
4. Фильтруйте список: Все / В диапазоне / 📗 / 📕 / 🟡 / 📘.
5. В колонке «Папка» — текущий статус глагола цветом (Выучено / Невыучено / Повторено / Новое); изменить статус из таблицы нельзя, только через Тренажёр или Карточки.
6. Для самопроверки включите «Скрыть перевод» и/или «Скрыть Perfekt» — ячейки размоются, клик по ячейке покажет ответ.

## 7. Вкладка «Карточки» — интерактивная колода для повторения

1. Переключитесь на вкладку **🗂️ Карточки**.
2. На экране настройки задайте диапазон глаголов. Ниже — панель «Что повторяем?» (📘/📕/🟡/📗, по умолчанию отмечены все 4 статуса): тапните по папке, чтобы включить/исключить её из подборки. Нажмите **▶ Начать**.
3. Карточка открывается в виде 1: инфинитив + Präsens · Präteritum · Perfekt на размытой иллюстрации, в углу — бейдж текущего статуса.
   - **Тап** по карточке → показывается перевод вместо форм (иллюстрация остаётся размытой).
   - **Ещё тап** → иллюстрация становится чёткой, весь текст скрывается, кроме примера предложения на немецком внизу карточки.
   - **Ещё тап** → карточка возвращается к виду 1.
4. **Свайп** карточки вправо («помню») или влево («не помню») — либо стрелки ←/→ на клавиатуре:
   - **Вправо** — карточка ставится в 🟡 «Повторено» (кроме уже 📗 «Выучено» — этот статус свайп вправо не понижает) и **пропадает из текущего набора**.
   - **Влево** — карточка ставится в 📕 «Невыученное» (даже если была 📗 «Выучено» — слово забыто и возвращается в пул незнакомых) и **остаётся в наборе**, чтобы показаться снова.
   - Единственный способ заново получить 📗 «Выучено» — правильный ответ в Тренажёре.
5. Набор сокращается по ходу повторения: карточки, просвайпанные вправо, больше не появляются в этой сессии. Когда набор опустеет (все просвайпаны вправо), откроется экран **«Повтор завершён»** с кнопками «Перейти к тренажёру» (тест по этому же диапазону) и «На главную».
6. Не обязательно доходить до конца: вверху экрана карточек есть кнопки **«Завершить»** (вернуться к настройке набора) и **«Перейти к тренажёру»** (сразу начать тест по этому диапазону, статусы карточек при этом не меняются).
7. **Иллюстрации** встроены прямо в файл `DieFliegendeKuhApp.html`, отдельная папка с картинками не нужна. Сейчас заполнена только часть из 270. Чтобы добавить свои: положите файлы `NNN-инфинитив.webp` в локальную папку `verb-images/` (номер соответствует № из таблицы; формат — WebP, ~800×1200 px, ~30–80 КБ) и запустите `python tools/embed-verb-images.py` — полный список имён и правила в `tools/verb-images.md`. Пока файла для глагола нет, карточка показывает нейтральную заглушку 🐄 — остальной функционал работает как обычно.

## 8. Small Talk (DTB B2)

На главном экране (вкладка «Тренажёр») над настройками есть отдельная кнопка **💬 Small Talk** — тренажёр устной части «Small Talk» экзамена DTB B2.

1. На карте две темы — **Thema A** и **Thema B**, текст скрыт (размыт).
2. Нажмите на Thema A — тема откроется и запустится таймер на **2 минуты**. Говорите на эту тему.
3. Когда время выйдет — плашка «Zeit ist um!», звуковой сигнал, вибрация (на телефоне) и, если разрешено, системное уведомление. Затем нажмите на Thema B.
4. Кнопки внизу: **Отмена** — остановить таймер, **Заново** — снова 2:00 для текущей темы, **Новая карта** — другая пара тем.
5. «Показать перевод» под картой — перевод открытых тем на выбранном языке интерфейса (RUS/ENG/ITA).
6. Темы выдаются случайно и не повторяются, пока не пройдена вся колода из 77 тем. Кнопка «🏠 На главную» возвращает к глаголам (идущий таймер при этом останавливается).

## 9. Сохранение и перенос прогресса

- Прогресс сохраняется **автоматически в браузере** (localStorage) — при повторном открытии файла в том же браузере на этом же устройстве всё восстановится.
- Если очистите данные браузера или откроете файл в другом браузере/на другом устройстве, прогресс не подтянется автоматически — используйте экспорт/импорт:
  - **Экспорт**: кнопка экспорта сохранит JSON-файл с именем вида `verben_progress_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.json`.
  - **Импорт**: на новом устройстве/в другом браузере откройте приложение и импортируйте этот JSON-файл — прогресс восстановится.

## Требования

- Любой современный браузер (Chrome, Firefox, Edge, Safari).
- Интернет и сервер не нужны — файл работает локально, офлайн.
